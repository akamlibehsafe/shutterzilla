# 0026 - Negative App On Hold for MVP Release

## Status
Accepted

## Context
Shutterzilla has three planned applications:
1. **Scraper** - Web scraping tool for vintage camera listings
2. **Collections** - Camera collection management
3. **Negative** - Film and analogue photo collection management

The MVP (Minimum Viable Product) strategy prioritizes delivering core functionality with Scraper and Collections apps first. Negative app is a valuable addition but not essential for the initial release.

## Decision
**Negative app is on hold for the first MVP release.**

**MVP Scope:**
- ✅ Scraper App (all pages)
- ✅ Collections App (all pages)
- ❌ Negative App (deferred to post-MVP)

**Rationale:**
- Focus development resources on core camera marketplace and collection features
- Validate product-market fit with Scraper and Collections before expanding
- Negative app requires additional design and specification work
- Mobile companion aspect of Negative adds complexity beyond MVP scope

## Current State
- Negative app placeholder page (`negative-home.html`) exists for future reference
- Negative app included in app switcher and navigation for consistency
- Negative app description and branding defined
- UI specifications not yet finalized

## Future Work
After MVP release:
1. Complete Negative app UI specifications
2. Design mobile companion interface
3. Define film tracking data model
4. Implement Negative app features
5. Integrate with mobile app

## Consequences
**Positive:**
- Faster MVP delivery focusing on core features
- Reduced initial development complexity
- Clear product focus for first release
- Easier to validate and iterate on core features

**Negative:**
- Film photography enthusiasts must wait for Negative app
- Incomplete product offering initially
- Need to manage user expectations about Negative availability

## Notes
- Negative app remains in navigation and documentation for future reference
- Placeholder page serves as design reference for future implementation
- Decision can be revisited if user demand for Negative app is high
